PUMPFONE WEBSITE — EASY EDIT VERSION

FILES
-----
index.html     = all website text + SEO
styles.css     = colors, sizes, layout and responsive design
site-config.js = BUY / TELEGRAM / X links (easiest file to edit)
script.js      = mobile menu and FAQ
assets/        = images

QUICK START
-----------
1. Open site-config.js.
2. Replace:
   YOUR-BUY-LINK.com
   YOUR_TELEGRAM
   YOUR_X_ACCOUNT
3. Open index.html and replace YOUR-DOMAIN.com.
4. Search "EDIT HERE" / comments if you want to change text.
5. Upload the whole folder to your hosting.

IMPORTANT
---------
The mascot is currently represented with placeholders so the website
works immediately. For the final design, replace the mascot blocks with
your transparent PNG/WebP artwork.
